# reims-gui (archived)

This is the former Rust/egui desktop app, kept read-only for reference. It is **archived and
unsupported**: nothing in this repository builds, tests or releases it, and no CI workflow runs it.
Its last release was `reims-gui-v0.1.6`; its builds (0.1.5 and 0.1.6) are kept in the [`archive`](https://github.com/jniltinho/kvm-gui/releases/tag/archive) release.

kvm-gui (Go + Wails, at the repository root) replaces it and reads the same VMs. See the
OpenSpec change `migrate-gui-to-go-wails`.
