# Tasks

Everything builds and runs inside the Docker image: every `make` target wraps `docker run`, and no task installs or uses Go, Node, Rust or GTK headers on the host. Every group ends with `make dist` writing every artifact the group has to `dist/` with `SHA256SUMS` (checked with `sha256sum -c`), then a Codex review: `codex exec -s read-only -C . "<review prompt naming the group's files, the specs it implements, and asking for P1/P2 findings and anything copied from VirtualBox or virt-manager>"`. P1/P2 findings are fixed before the group's review task is checked. Before each group, look up earlier decisions with ai-memory and the callers of the code it changes with the codebase-memory graph. GUI checks with agent-desktop run in the GNOME containers, never on the user's desktop without asking. Never run two QEMUs on the same disk; shut the Nilton VM down over SSH. For anything Reims vGPU, `steelbrain/reims-vgpu` is the base reference.
